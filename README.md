# 3D Animation - Jewelry Display Stand

A premium 3D scrolling website with scroll-linked animations for product showcase.

## Features

- **Scroll-Linked 3D Animation** - 3D model rotates, moves, and scales based on scroll position
- **STL Model Support** - Load your own 3D STL model
- **Fallback 3D Object** - If STL fails to load, a TorusKnot is displayed
- **Color Options** - Gold, Silver, Rose Gold, Black variants
- **Responsive Design** - Works on all devices
- **Smooth Animations** - Glassmorphism UI with fade-in effects
- **Progress Bar** - Shows scroll progress
- **Particle Effects** - Ambient floating particles
